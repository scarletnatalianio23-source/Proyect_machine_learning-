# Data dictionary: `forest_loss_municipalities.csv`

> **Simulated dataset.** Municipality names and departments are real and areas are
> approximate, but population, cattle, planted area, poverty index and forest loss
> are generated by `generate_dataset.py` (seed 2026). They are not official
> IDEAM, DANE or SMByC figures.

One row = one municipality in one year (2015-2023): 188 municipalities, 1,692 rows.

| Column | Unit | Meaning |
|---|---|---|
| `municipality`, `department`, `region` | text | Real names; region is Andean, Caribbean, Pacific, Orinoquia or Amazon |
| `year` | year | 2019-2023 |
| `area_km2` | km2 | Approximate surface (form input) |
| `population` | people | Simulated (form input) |
| `cattle_heads` | heads | Simulated (form input) |
| `planted_area_ha` | ha | Simulated (form input) |
| `nbi_pct` | % | Simulated unmet basic needs index (form input) |
| `coca_ha`, `armed_groups` | ha / count | Simulated, used only to generate the target |
| **`forest_loss_ha`** | ha | **Target:** forest lost in that year |

Models compared (5-fold GroupKFold by municipality, target log(1 + forest_loss_ha)):
multiple linear regression, Random Forest and Gradient Boosting. Results are in the
"Models" page and in `models/report.json`. Retrain with `python train_models.py`.

Inspired by: Mendoza Montoya, E. (2025). *Municipal-level data on deforestation, prosecutions,
and socioeconomic indicators in Colombia (2021-2023)* (Version 1) [Data set]. Mendeley Data.
https://doi.org/10.17632/mn5s748pyt.1
