Which model should forecast forest loss?

Three Machine Learning models are tested on the same task and the same data. We compare them, analyze the differences and conclude which one is the most suitable for this project.

The task

Forecast the hectares of forest a municipality will lose next year, using how much it lost in the last three years and its current conditions: area, population, cattle, planted area, unmet basic needs, coca cultivation and armed groups. The data cover {{ b.municipalities }} municipalities from {{ b.years[0] }} to {{ b.years[-1] }} (simulated, inspired by public municipal data).

{% call plain() %}We give each model the last three years of forest loss of a town plus a few facts about it, and ask it to guess how much forest the town will lose next year. Then we check which model guesses best.{% endcall %}

1. Multiple linear regression

Draws the best straight-line relationship between the inputs and the log of next year's loss.

Like drawing the best straight line through the past.

Strength Simple, fast, easy to explain.

Limit Cannot capture interactions, such as cattle and area reinforcing each other.

2. Random Forest

Hundreds of decision trees trained on different samples; the forecast is their average (Breiman, 2001).

Like asking hundreds of experts and taking the average of their answers.

Strength Handles non-linear patterns and outliers with little tuning.

Limit Less transparent; cannot extrapolate beyond the values it has seen.

3. Gradient Boosting

Trees built one after another, each one correcting the mistakes of the previous ones (Friedman, 2001).

Like a relay team where each member fixes the previous one's mistakes.

Strength Often the most accurate on tabular data.

Limit More sensitive to settings and to small datasets.

How the comparison was made

A forecasting model must be tested on the future, not on random rows. For each test year the models were trained only with earlier years and then asked to forecast that year, which they had never seen:

Technical details

MAE is the average mistake in hectares. RMSE also punishes big mistakes. R² (log scale) is the share of variation explained, measured on the logarithmic scale the models learn on. Two simple rules are included as a reference: same as last year and average of the last 3 years.

Analysis and deductions

1. The winner is consistent

{{ model_names[best] }} has the lowest MAE ({{ m[best].mae }} ha) and wins in {{ year_wins }} of the {{ b.test_years|length }} test years. {% if ns.rmse == best %}It also has the lowest RMSE, so it makes fewer large mistakes.{% else %}{{ model_names[ns.rmse] }} has the lowest RMSE, so it makes fewer large mistakes.{% endif %}

2. The models are close

The best and the worst MAE differ by only {{ spread }}%. {% if ns.r2 != best %}On the log scale, {{ model_names[ns.r2] }} has the best R² ({{ m[ns.r2].r2_log }}).{% endif %} With this much data, the choice matters less than having good inputs.

3. Recent history is the key input

In {{ model_names[best] }}, {{ b.lag_share[best] }}% of the decisions depend on the losses of the last three years ({{ b.lag_share.linear }}% in the linear model). Deforestation is persistent: places that lost forest recently tend to keep losing it.

4. The gain over simple rules is modest

Compared with "same as last year" ({{ base['Same as last year'].mae }} ha), {{ model_names[best] }} lowers the MAE by {{ gain_last }}%. The models add what a rule cannot: the effect of conditions such as cattle or coca, a likely range, the chance of a high alert and what-if scenarios.

5. More complex is not always better

{% if m.boosting.mae < m.forest.mae %}Gradient Boosting beat Random Forest on MAE, so extra complexity paid off.{% else %}Gradient Boosting did not beat Random Forest ({{ m.boosting.mae }} against {{ m.forest.mae }} ha).{% endif %} {% if m.linear.mae < m.boosting.mae %}The simple linear regression was also ahead of it.{% else %}The linear regression was behind it.{% endif %} Boosting needs careful tuning and more data than the {{ b.rows }} records available.

6. Limits to keep in mind

The data are simulated, so these numbers show the method, not the real state of Colombia. The scenario simulator shows associations learned from the data, not proven cause and effect.

Conclusion: {{ model_names[best] }}

It gives the lowest average error ({{ m[best].mae }} ha), is the most stable across the test years and handles the uneven, outlier-heavy shape of deforestation better than a straight line. It is therefore the final model of this platform, and it is the one used in the next step to forecast, classify alerts and simulate scenarios.

In plain words: it is the model that guesses best and makes the smallest mistakes, so it is the one that makes the predictions.
